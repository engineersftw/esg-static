Speaker: Stephan February

According to the Third Principal of Twelve Factor Applications, we should store our configuration in the environment. This is especially useful in a microservices architecture where you can have dozens of small applications that need to be configured. Stephan February will be presenting a talk on how to use the Config Server facility in Pivotal CloudFoundry to achieve an externalised, cloud-based application configuration. 

Stephan February is a Software Engineer at Pivotal Labs Singapore
