Speaker: Pratibha Jagnere, Senior Python Developer

This talk aims to help developer and sysadmins who want to learn about centralized log management solution. By the end of the talk, Attendees will learn how to use Graylog to visualize application logs, as well as guidance on how to write their own log data extractor for unstructured logs.

About the speaker:

Pratibha is a Senior Python developer over looking the development and maintenance of the backend including APIs and application oriented DevOps work. She is a coder by passion and Freelancer by choice.
