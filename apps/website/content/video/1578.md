Speaker(s): Aayush Arora (Noida)

Abstract: 

Open-event Webapp generator can generate event websites by getting data from event JSON files and binary media files that are stored in form of ZIP. 

The talk will focus on some features in Open-event-webapp generator, the client-side implementations for webapp and optimizations including pageload time and performance issues.
