Get started with Taqwright, mobile UI test automation on the Playwright runner with a flat locator API on top of Appium 3. In this walkthrough we go from zero to a passing Android test: install the package, scaffold a project with init, run the sample test on an emulator, and open the HTML report.

What you'll see:
• Installing Taqwright from npm
• Scaffolding a project with npx taqwright init
• Running the first test on an Android emulator
• Viewing results in the HTML report

Chapters:
0:00   Install Taqwright from npm
0:10  Scaffold a project (npx taqwright init)
0:43  Run the taqwright doctor command
0:52  Run the taqwright devices command
1:09  Running the tests
2:05 Viewing the HTML report

Commands used:
  npm install --save-dev @taqwright/taqwright@latest
  npx taqwright init
  npx taqwright doctor
  npx taqwright devices
  npx taqwright test
  npx taqwright show-report
