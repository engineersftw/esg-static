An introduction for experienced programmers into the basics of Python syntax and functionality.
Our director Yue Lin Choong, pythonista in training, will be showing us the tips and tricks of this powerful language.

• Install Anaconda (https://www.continuum.io/downloads) (Python 3 will be used). This will install Python and Jupyter Notebook (http://jupyter.org/), which we will use for our workshop.
• Clone Python Tutorial (https://github.com/wwcodesg/python-tutorials) github repository.
• This Workshop assumes programming background.
