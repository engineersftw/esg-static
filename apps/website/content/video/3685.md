Speaker: Kim Morano
"Are you a frontend developer wanting to try designing the backend? Do you want to build something without much of the backend headache? Do you want to try something new?

Let's build with Gatsby and Hasura! Gatsby is a React-based framework used to built fast websites and Hasura is an instant, realtime GraphQL APIs over Postgres.

This talk will be about the powerful combination of Gatsby and Hasura in building fast websites powered by modern technologies such as React and GraphQL. A project built applying the two technologies will be demonstrated."
