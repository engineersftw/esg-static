Speaker: Nagaraj Venkatesan

"R", a popular statistical language among data scientists has been integrated with SQL Server 2016. Now, with SQL Server 2016, one gets to perform the data retrival and statistical compute in one box. The session will provide an overview on how R works with SQL Server 2016 and the benifits of using Microsoft R in data science process. The session will also provide a quick introduction for T SQL Deveoplers and DBAs on how "R" code can be deployed to SQL Server 2016.

Speaker Profile: Nagaraj Venkatesan

Nagaraj Venkatesan, a SQL Server enthusiast exploring SQL Server for the last 10 years. Working for NCS Pte Ltd as SQL Server DBA, Nagaraj maintains databases used by one of the busiest public facing applications in the city. He frequently blogs at strictlysql.blogspot.com and is a regular contributor sqlservercentral.com. Besides these, he also holds a Masters Degree in Computing from National University of Singapore
