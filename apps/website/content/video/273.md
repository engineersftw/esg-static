Topic: Migrating your Windows Phone and Windows 8.1 XAML applications to the new Windows 10 Universal App Platform

Speaker: Lia Kampantai

Lia Kampantai is a .NET developer from Greece, and a Microsoft MVP since 2013. She started developing Windows Phone applications in 2011, and has delivered several seminars and hands-on labs regarding Windows Phone and Windows 8.1 platform development during the past years.

Summary

In this presentation we will talk about:

• Why you should migrate your existing apps to the new Universal Windows Platform

• What’s new in XAML

• Responsive UI design

• Using existing code

• The submission process to update the app
