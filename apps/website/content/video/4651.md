Frontend frameworks have grown a lot in the past few years. There are many features that are made super easy for developers, and this is becoming more efficient day by day. More and more developers are now interested in the web, and all thanks to Javascript which enabled developers to build seamlessly and do crazy things. You can now even build for any platform just using web technologies. This is amazing for building omnichannel experiences, and for JavaScript developers.

Headless is one of the growing fields along with the web. Many enterprises and developers are moving over to the headless ecosystem, making the complete building process and experience smooth for everyone involved. In this talk, we will discuss using Headless with modern frontend frameworks. 
We will take a look at the benefits of Headless, and how powerful the combination of Headless and all the Javascript frameworks become with the capabilities combined. With a little hands-on, I will show you how we can get started with using Headless with React.

We will explore how Headless and Javascript can help give a better experience to everyone including developers, content editors, and marketers on the building side along with the users using our app by providing them with personalized content.
