I like to jam with other musicians using my self-made software-based MIDI controller, so that I can play music with just my computer. And it is only possible with the web platform supporting MIDI. In this talk I will show you the world of MIDI, and how the Web MIDI API makes it easy for anyone to create their own MIDI software. Through many demoes, I will show how a web page can interact with various musical instruments and softwares. You’ll see that when the Web Platform and the MIDI ecosystem combine, together they unlock many use cases and reduces barrier to entry at the same time.
