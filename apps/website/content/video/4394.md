"Any fool can write code that a computer can understand. Good programmers write code that humans can understand." – Martin Fowler
Writing clean, understandable, and maintainable code is a skill that is crucial for every developer to master. Code which is easily understandable, eventually can be easily enhanced.

In this session, we will cover:

* What are code smells
* How do you write clean code
* How to refactor from bad code to clean code
* Good practices to have a cleaner code
