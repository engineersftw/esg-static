Stop hand-writing locators. taqwright codegen opens a browser-based inspector against a real device or emulator, and as you tap and type, it records a fully runnable test and picks the most stable locator for every element you touch.

In this video:
- Start the inspector with one command (npx taqwright codegen)
- Connect to a local emulator or a cloud device (BrowserStack / LambdaTest)
- Record taps, typing, swipes, and gestures into a spec
- Let codegen rank locators by uniqueness and stability (resource-id / accessibility-id first)
- Add assertions from the UI (visible, text, value, count, …)
- Export the spec to your project and run it with npx taqwright test

taqwright is a Playwright-runner + flat locator API over Appium 3, so you get parallel runs, retries, the HTML reporter, and a familiar test/expect API, but you drive a phone instead of a browser.
