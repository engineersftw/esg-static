Speaker:  Deepak Karki, PES Institute of Technology

Description:
I will be covering the developer tools available to build cyber physical
systems using opensource hardware and software (in this case, the
Beaglebone Black and the Python programming language). The talk will cover 3 main tools available to the developer community.

1. PyBBIO - Beaglebone IO using python. I'm a co-author for this project.

Link : https://github.com/alexanderhiam/PyBBIO

2. PRUSepak - Real time control using the PRU remote-processors on the Beaglebone Black. I'm the primary author for this project.

Link : https://github.com/deepakkarki/pruspeak

3. Project Zygote - A IoT framework centered around the Beaglebone Black.
Written using Flask, a python based web framework. I'm the primary author for this project.

Link : https://github.com/kres/zygot
