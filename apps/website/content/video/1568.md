Description: NodeRED is programming tool that provides a great browser interface to wire together hardware devices, APIs and online services. Stephan is an IBM Code Mage who started coding with COBOL. He's a frequent speaker on IT related topics and interested in mobile and IoT. He's blogging for more than a decade at wissel.net.
