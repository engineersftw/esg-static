Speaker: Desmond Koh

For the first time, Apple is giving developers the ability to create their own machine learning models through Create ML with Xcode’s Playgrounds! All we need is some data and we’re ready to go!

In this presentation, Desmond will be sharing some of the basic features of Create ML to build a local food image recognition prototype with Create ML and Core ML, where you can run machine learning models on your device and the data doesn’t need to leave the device to be analysed! (Create ML is still in beta at the time of writing)
