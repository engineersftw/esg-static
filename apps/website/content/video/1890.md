Speaker: Istvan Szmozsanszky (@flaki)

Slides: http://talk.flak.is/play/sg/

Description:  Ever wanted to put some games on a microcontroller? No? Well, it's about time you unleashed your imagination! And in case you would be complaining about C++ right now... hold it right there, your trusty old friend, JavaScript will help you out here, too. ;)

We will have a look at MicroCanvas a tiny HTML5 Canvas games framework for creating pixelgraphic HTML5 games that work in any web browser, desktop or mobile - and for an added bonus see how these can be compiled and flashed on tiny microcontrollers to be played on small, arduino-based custom built gaming rigs.
