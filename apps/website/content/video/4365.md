Speaker: Pawel Fraczyk, Founder at DevOps Codes

This talk will demonstrate the solution built using Terraform starting with the quick overview on how to build a CI/CD Pipeline using CodeCommit/CodeBuild/CodePipeline and deploy Docker containers from ECR to ECS Clusters in multiple regions & accounts. We will also see how to manage geolocation traffic by way of using ALB and Route53.
