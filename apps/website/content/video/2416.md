Speaker: Ajo Robert
Info: https://2018.fossasia.org/event/speakers.html#ajo-robert3208

This talk will go through two main features of MySQL with examples quite relevant to the distributed NoSQL &amp SQL era of applications. First part will go through the usage of MySQL JSON as both NoSQL and SQL data store at the same time with examples and use cases. The second part will concentrate on distributed transaction standard and how MySQL can be used as a resource manager in such a distributed transaction which can span across heterogeneous functional nodes and across geography.
