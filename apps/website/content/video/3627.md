Speaker:
Veha Suwatphisankij

Javascript environment is more significant than ever, but for any Clojurian, writing program in JS is never satisfying. In this talk, he will show us how to write frontend code or any JS environment code and build it with shadow-cljs, which could help to quickly interop cljs code with JS world. This talk feature JS interop, reagent, re-frame, next.js, and more.
