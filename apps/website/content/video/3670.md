Mixed reality devices use always-on cameras and sensors to overlay virtual elements on the physical world. User privacy is an existential and essential question for this technology. This talk offers an overview of Mozilla’s approach to building an immersive web browser and a social VR platform that empowers users.

Diane Hosfelt is the security lead for the Mixed Reality team at Mozilla and works closely with the Rust Project to improve security with formal methods and unsafe code guidelines.
