Resilient Microservices Architecture with Kubernetes

Microservices architecture is becoming quite common nowadays.
Microservices have been around for some time, but container technologies are helping organisations to adopt new tools and techniques at a much faster pace. The talk will demonstrate how to build resilient Microservices using specific design patterns. Some of the patterns we will cover:

1 – Timeout design patterns

2 – Circuit breaker design pattern

3 – Retry design pattern

4 – Bulkheads design pattern
