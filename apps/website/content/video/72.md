Speaker: Stefan Koehler, CronusConsult 

Description:
The LiMux project has gained worldwide attention in 2003 when the City Of Munich decided to replace Windows with a linux--based client. Today more than 15.000 clients run LiMux. LiMux heavily relies on popular FOSS components like (K)Ubuntu, LibreOffice or Firefox but also adds some self-made magic ingredients. This talk will shed some light on the techniques used and how they work together.
