Elasticsearch is a distributed search engine that provides lots of features for searching different kinds of data. In this quickie we will see how Elasticsearch stores and processes text and how it can be used to do full text search for the languages of Singapore.

Florian Hopf (Zenika)
Florian is working as a backend developer and consultant with a strong focus on search applications built on Lucene, Solr and Elasticsearch. He blogs at http://blog.florian-hopf.de and has written a German book on Elasticsearch
